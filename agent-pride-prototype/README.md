# Agent Pride Prototype

A static 10-slide presentation app for the Agent Pride Prototype concept.

## Files

- `index.html` - app shell and controls
- `styles.css` - visual design, slide layouts, and responsive behavior
- `script.js` - slide content data and navigation logic
- `assets/` - SVG visual assets used by the deck

## Use

Open `index.html` in a browser. Use the side navigation, the previous/next buttons, or keyboard arrow keys to move through the deck.

Use the `PDF` button to print or save the presentation as a PDF.
